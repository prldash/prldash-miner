# PRLDASH

Mine Pearl (PEARL) on your NVIDIA RTX 30, 40 or 50 graphics card.

## Download

- **Windows** — [PRLDASH.zip](https://github.com/prldash/prldash-miner/releases/latest/download/PRLDASH.zip) (extract, run `PRLDASH.exe`, paste your wallet, press Start)
- **Linux** — [prlminer-linux.tar.gz](https://github.com/prldash/prldash-miner/releases/latest/download/prlminer-linux.tar.gz) · [steps](https://prldash.com/start/#linux)
- **HiveOS** — custom miner URL `https://prldash.com/hiveos/prlminer-0.2.5.tar.gz` · [steps](https://prldash.com/start/#hiveos)
