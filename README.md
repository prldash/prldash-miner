# PRLDASH

Mine Pearl (PEARL) on your NVIDIA RTX 30, 40 or 50 graphics card.

## Download

- **Windows**: [PRLDASH.zip](https://github.com/prldash/prldash-miner/releases/latest/download/PRLDASH.zip). Extract it, run `PRLDASH.exe`, paste your wallet and press Start.
- **Linux**: [prldash-miner-linux.tar.gz](https://github.com/prldash/prldash-miner/releases/latest/download/prldash-miner-linux.tar.gz) · [steps](https://prldash.com/start/#start-linux)
- **HiveOS**: custom miner. The current installation URL and settings are on <https://prldash.com/hiveos/>.
